# Klavesin — правила для сессий и агентов

Что это: настройка мини-клавиатур по USB, окно на egui/eframe (набор Anvil). Состояние и долги
владельца — [HANDOFF.md](HANDOFF.md); замысел и этапы — [SPEC.md](SPEC.md); документация того, что
есть сейчас — [docs/README.md](docs/README.md); работа идёт через OpenSpec (`openspec/changes/<имя>`).
Весь текст пользователю — по-русски; тексты в интерфейсе — RU/EN, светлая и тёмная тема.

## Части

- `crates/klavesin` — окно программы: eframe 0.36.2 + `anvil-ui` (тег набора `kit-v1.0.0`, как у
  Amber и Morok).

## Общие скрипты

- Готовые помощники — `E:\dev_personal\tools\` (оглавление `README.md` там): `patch.py`, `checks.py`,
  `bump_version.py` и др. Скрипты самого проекта — в `scripts/`.

## Диски

- Только **E:** — репозиторий, worktrees, `target`, логи. Общая папка — `E:\dev_personal\Klavesin-scratch`
  (отчёты агентов — `reports\`, сборка судей — `target-judge\`). D: запрещён, R: мал для сборок.

## Сборка и проверка (на ПК; CI — только по слову владельца)

- По ходу — только затронутые крейты (`cargo check -p klavesin`, `cargo test -p klavesin`), `-j 4`.
- Перед сдачей один раз: `python E:/dev_personal/tools/checks.py --repo . -j 4 fmt test clippy`
  (программа только под Windows — шаг `zig` не нужен, как у Kamerton).
- Результат — по коду выхода; вывод в файл, в разговор хвост.

## Работа агентов

- Исполнитель — свой worktree, коммиты по-английски в своей ветке, не пушит; называет ветку и хэш.
- Судья и сверщик документации — без worktree, читают `main`, собирают в `target-judge`.
- Отчёт — до ~25 строк, подробности в `Klavesin-scratch\reports\<имя>.md`.
- Версию агент не меняет, если задача этого прямо не требует.

## Интерфейс

- Любая работа с видом — по [docs/ui-guideline.md](docs/ui-guideline.md) и общему гайдлайну UX/UI
  (скил `ui-guideline`); новое правило или решение владельца — в гайдлайн в том же шаге.

## Документация и коммиты

- Изменил поведение, команду, экран, формат файла — в том же шаге поправь `docs/`.
- Коммиты — по-английски. Пуш, выпуск и тег — по команде владельца.
