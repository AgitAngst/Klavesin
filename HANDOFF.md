# Klavesin — состояние

Обновлено: 31.10.2026, версия 0.3.0.

## Где остановились

Этап 0.3 сдан: опрос USB HID (`usb.rs`, крейт `hidapi 2.6.7` — разрешение владельца, вопрос
«где моя клавиатура?»). Программа при запуске и по «Обновить список» находит реальные устройства:
системные мыши/указатели и «корневые коллекции» Windows (vid:pid = 0) отсеяны; устройству без
строк даётся имя «USB HID vid:pid». На машине владельца видны ASUSTeK HID, HIDI2C и USB HID
1189:889 (0x1189 = зона для макропадов, вероятная трёхклавишная). Снимки: `Klavesin-scratch
\shots\usb-*.png`. Следующий этап — 0.4: редактор раскладок + чтение нажатий/запись в
устройство (нужен протокол устройства владельца: что оно принимает и шлёт).

## Долги и ждёт решения

- Раскладка найденного устройства условная (3 клавиши в ряд) — заменит редактор раскладок (0.4).
- Чтение нажатий и запись в устройство нереальны — кнопки меняют состояние, по HID ничего не
  уходит. Нужно решение владельца о протоколе устройства (или целевом устройстве-прошивке).
- Знак программы (иконка окна и exe) не подключён; акцент Plum ждёт переноса в набор (`Accent::PLUM`).
- Общие настройки не сохраняются между запусками — 0.6.
