## Что это и что уже работает

Klavesin — настройка мини-клавиатур по USB. Работает: опрос USB HID — программа при запуске и
по кнопке находит реальные устройства (системные мыши/указатели и «корневые коллекции» Windows
отсеяны; устройству без строк даёт имя из vid:pid) и показывает их слева; дальше первый экран:
колонка профилей, слои, карта клавиш с выбором и назначением (клавиша/сочетание/текст/макрос/
слой), черновик с переключателем, «Записать на клавиатуру», пустое состояние, настройки набора
(тема/язык), «О программе», строки RU/EN, обе темы, акцент Plum. Раскладка найденного
устройства пока условная (один ряд из трёх клавиш) — её заменит редактор раскладок (0.4).
Не сделано: чтение нажатий и запись в устройство (кнопки честно меняют состояние, по HID
ничего не отправляют), подсветка.
