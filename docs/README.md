## Что это и что уже работает

Klavesin — настройка мини-клавиатур по USB. Работает: опрос USB HID (реальные устройства,
без мышей и «корневых коллекций» Windows); для знакомого устройства 1189:8890 («MINI KeyBoard»,
прошивка с вендорным HID-протоколом) — своя карта (3 клавиши + ручка: поворот/нажатие/поворот),
запись назначений в устройство по кнопке «Записать на клавиатуру» (клавиши, сочетания,
медиаклавиши — прошивкой поддерживается; текст и макросы честно пропускаются с итогом),
подсветка — 4 пресета прошивки. Назначения устройство обратно не отдаёт — их хранит Klavesin.
Дальше первый экран: колонка профилей, слои, карта с выбором и назначением, черновик, пустое
состояние, настройки набора, «О программе», строки RU/EN, обе темы, акцент Plum. Протокол:
`crates/klavesin/src/device.rs` (источники — в заголовке файла). Не сделано: хранение профилей
между запусками (0.6), редактор раскладок для незнакомых устройств (0.5), чтение нажатий
с подсветкой нажатой клавиши.
