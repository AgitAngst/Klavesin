## Что это и что уже работает

Klavesin — настройка мини-клавиатур по USB. Работает: опрос USB HID (реальные устройства,
без мышей и «корневых коллекций» Windows); для знакомого устройства 1189:8890 («MINI KeyBoard»,
прошивка с вендорным HID-протоколом) — своя карта (3 клавиши + ручка: поворот/нажатие/поворот),
запись назначений в устройство по кнопке «Записать на клавиатуру» (клавиши, сочетания,
медиаклавиши — прошивкой поддерживается; текст и макросы честно пропускаются с итогом),
подсветка — 4 пресета прошивки. Назначения устройство обратно не отдаёт — их хранит Klavesin: тема, язык, выбор устройства,
черновик, раскладки и профили сохраняются между запусками (eframe storage, JSON). Редактор
раскладок: диалог «Раскладка…» у устройств без заводской раскладки (колонки 1–8, ширина клавиш,
добавление/удаление). Протокол: `crates/klavesin/src/device.rs` (источники — в заголовке файла).
Не сделано: чтение нажатий с подсветкой нажатой клавиши, расширение протокола (макросы до 5
нажатий, мышь), знак программы.
