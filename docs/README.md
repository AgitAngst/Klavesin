# Klavesin — документация

Версия программы: 0.2.0

Это документация того, что есть сейчас. План и этапы — [SPEC.md](../SPEC.md), заметки для следующей
сессии — [HANDOFF.md](../HANDOFF.md).

## Что это и что уже работает

Klavesin — настройка мини-клавиатур по USB. Работает: первый экран по доске (решения
владельца 31.10.2026) — список клавиатур слева, колонка профилей справа, вкладки слоёв, карта
клавиш с выбором и назначением (клавиша/сочетание/текст/макрос/слой), черновик с переключателем,
«Записать на клавиатуру», пустое состояние с поиском, настройки набора (тема/язык), «О
программе», строки RU/EN, светлая и тёмная темы, акцент Plum. Список клавиатур сейчас —
выдуманный демо-набор; опрос USB — этап 0.3. Не сделано: подключение клавиатур и запись в
устройство (кнопки честно показывают состояние, USB не трогают), подсветка, редактор раскладок.
