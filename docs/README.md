# Klavesin — документация

Версия программы: 0.1.0

Это документация того, что есть сейчас. План и этапы — [SPEC.md](../SPEC.md), заметки для следующей
сессии — [HANDOFF.md](../HANDOFF.md).

## Что это и что уже работает

Klavesin — настройка мини-клавиатур по USB (сейчас заглушка). Работает: окно на eframe 0.36.2 с
общим оформлением набора Anvil (светлая/тёмная тема, акцент `BLUE`), шапка с названием, карточка с
пояснением и главной кнопкой, версия в строке состояния. Не сделано: подключение клавиатур,
назначение клавиш, слои, подсветка, настройки программы, перевод строк программы на EN.
