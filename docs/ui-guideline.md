# Гайдлайн интерфейса Klavesin

Правила вида окна Klavesin, сняты с кода 0.1.0 (31.10.2026). Доски-макета пока нет: первый
настоящий экран — по доске на холсте и слову владельца (общий гайдлайн §11). Общие правила —
общий гайдлайн UX/UI (скил `ui-guideline`, `common.md`); числа набора — `Anvil/docs/STYLE.md` и
`MOTION.md` (набор anvil-ui, тег `kit-v1.0.0`). Новый экран и правка вида — по этому файлу; правило
поменялось или появилось — поправить файл в том же шаге (журнал внизу).

Порядок, если источники расходятся: решение владельца → этот гайдлайн → общий гайдлайн → набор →
макет → код. Расхождение кода — долг («Известные отклонения»), а не новое правило.

## 1. Характер

Окно-инструмент: подключил клавиатуру — настроил — закрыл. Раскладка — окно-инструмент (шапка,
основная область, строка состояния); боковая панель появится со списком клавиатур. Акцент —
`BLUE` набора (по умолчанию, пока владелец не выбрал свой).

## 3. Цвета

Палитра набора (`anvil_ui::Palette`), акцент `BLUE` (`const ACCENT` в `main.rs`). Свои цвета не
заводятся.

## 4. Текст

Шкала набора. Заглушка использует `w::card_title` и `w::note`; версия в строке состояния.

## 5. Отступы и формы

Из набора: карточки `w::card`, поля основной области `chrome::content`.

## 6. Элементы и экраны

- Шапка: `chrome::top_bar` + `chrome::brand` (значок `Icon::Keyboard`, имя «Klavesin»).
- Содержимое заглушки: `w::card` — `w::card_title`, пояснение `w::note`, главная кнопка
  `w::button(Kind::Primary, …)`.
- Строка состояния: `chrome::status_bar`, версия справа.
- Настоящие экраны — после доски и слова владельца.

## 7. Движение

Из набора (`anvil_ui::motion`); своего нет, в заглушке не используется.

## 8. Языки и тексты

Строки набора — RU/EN, переводит набор; язык — из `CommonSettings` (по умолчанию язык системы).
Строки программы: заглушка по-русски, таблицы переводов ещё нет — см. отклонения. Консоль и логи —
по-английски, комментарии в коде — по-русски.

## 9. Общие правила

Как у набора Anvil: виджеты `anvil_ui::widgets`, каркас `anvil_ui::chrome`. Не подходит: —.

## 10. Как проверять

Снимки — `E:\dev_personal\tools\shoot_scenes.ps1` (сцен пока нет). Глазами: обе темы (системная
тема переключается в системе), размер по умолчанию и наименьший. Полный набор сочетаний
(светлая/тёмная × RU/EN × размеры) — один раз в конце этапа, перед сдачей.

## 11. Известные отклонения

Долги, а не правила; исправлять при первой правке этих мест.

- Строки заглушки без перевода на EN — таблица переводов появится с экраном настроек (0.6).
- Иконка окна и exe не подключены (нужен знак программы: квадрат акцента со значком, правила —
  `Anvil/docs/ICONS.md`).
